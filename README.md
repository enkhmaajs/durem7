# Дүрэм

Компанийн тухай хуулийн 16 дугаар зүйлд заавал тусгахаар шаардсан мэдээллийг алхам алхмаар цуглуулж, компанийн дүрмийн **төслийг** текст файл болгон гаргах статик веб хуудас.

## Ажиллуулах

`index.html` файлыг браузераар нээнэ. Сервер, package суулгах шаардлагагүй.

## GitHub-д хадгалах

1. GitHub дээр шинэ repository үүсгэнэ.
2. Энэ хавтасны файлуудыг repository руу upload хийнэ, эсвэл Git ашиглан commit/push хийнэ.
3. Repository-ийн үндсэн түвшинд `index.html` байгаа эсэхийг шалгана.

## Vercel-д байршуулах

1. Vercel-д нэвтэрч **Add New → Project** сонгоно.
2. GitHub repository-г холбоно.
3. Framework preset-ийг **Other** болгоно. Build command болон Output directory-г хоосон үлдээнэ.
4. **Deploy** дарна. Энэ нь цэвэр статик сайт тул build алхам шаардлагагүй.

## Мэдээлэл ба хуулийн эх сурвалж

Оруулсан мэдээлэл браузерээс сервер рүү илгээгдэхгүй, хуудасны хадгалалт/аналитик ашиглаагүй. Төсөл нь хуулийн зөвлөгөө, улсын бүртгэлийн баталгаа биш. Байгууллагын онцлог болон хууль тогтоомжийн бусад шаардлагатай нийцүүлэн мэргэжлийн хяналт хийлгэнэ үү.
